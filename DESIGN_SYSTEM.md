# Визуальная система Потока

Источник: 11 PNG (412×844) из «MOBILE - сервис подписок (1).zip». Это визуальный референс, а не спецификация функций.

## Токены

Фон #121212; поверхность #202020; поднятая поверхность #292929; текст #f5f5f5 / #b8b8bf / #96969f; граница #39393f. Primary #0038ff, hover #2455ff. Success #58df98, warning #f1c56e, danger #ff9292 — светлый текст на тёмных подложках. Сине-голубой градиент используется только для знакомства и подключения источников. Мягкое индиго-свечение у нижнего края повторяет «мои подписки».

Шрифт: системный гротеск (Arial на Windows); файл шрифта в архиве отсутствует. Заголовки 24–32, секции 20, основной текст 16, подписи 14, метаданные 12. Суммы 32–48, tabular-nums. Интерлиньяж 1.5, заголовки 1.2. Spacing 4/8/12/16/24/32/40/48. Radius 12 (малый), 16 (поля), 24 (карточки), 999 (капсулы). Тень только у плавающих панелей.

## Соответствие экранов

- Dashboard → «главная»: большая финансовая карточка, синий график с заливкой, компактные строки ближайших платежей.
- Расходы → «мои подписки»: карточки сервиса, логотип справа, стоимость и дата; фильтры-капсулы. На широком экране сетка карточек.
- Детали → «конкретная подписка»: выразительный блок логотипа, сумма, следующая дата, отдельные секции истории и управления.
- Add/Edit → «добавление подписки-1» и заполненная версия: графитовые поля, вертикальный ритм, синяя основная кнопка.
- Login/Onboarding → «первый экран» и «добавление подписки»: синий градиент, прозрачные поверхности выбора. Без семейных аккаунтов из референса.
- Import/Data Sources → те же карточки выбора и поля; явные состояния согласия, загрузки, ошибок.
- Detected/Recommendations → карточки сервисов и компактная подсказка с главной.
- Settings/Google setup/Privacy/Terms/Error → общая типографика, графитовые секции и кнопки.

## Повторно используемые паттерны

Токены централизованы в app/globals.css; существующие primitives сохраняют поведение. Button/IconButton, Card/StatisticCard, Input/Select, Badge, Tabs, Table, Dialog/AlertDialog, NavigationItem, EmptyState и SectionHeader используют эти токены. На мобильном плавающая навигация плюс отдельная кнопка добавления, формы в адаптивном диалоге. Desktop расширяет систему референса; точных desktop-макетов нет.

В архиве нет отдельных иконок, шрифтов или иллюстраций. Не вырезаем изображения с уже встроенным фоном и чужие аватары: сохраняем существующие логотипы сервисов и lucide-иконки. Не переносим системный status bar телефона и функции семейного доступа/виджетов.

## Проверки кода

Lint проверяет код приложения. Поставляемый каталог components/ui и временные work-файлы исключены из анализа. Обычные ссылки оставлены намеренно: приложение использует полную серверную навигацию. ARIA roles для SVG и live regions сохранены. Для node:test регистрация тестов не требует await; сценарии smoke используют проверяемые динамические JSON-ответы. Типизация старого XML adapter и его текущий validator сохранены без смены зависимости при визуальном рефакторинге.
